# Denset releases

Signed installers and the update file for [Denset](https://h0rsegg.github.io/denset-releases/), a Firefox extension for named sets of default tabs.

**To install, open https://h0rsegg.github.io/denset-releases/ in Firefox and click Install Denset.** Installed copies update themselves from `updates.json`.

This repository is published automatically by Denset's release script; please do not edit it by hand.
