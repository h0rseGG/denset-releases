Denset

Named sets of default tabs for Firefox, kept as bookmarks so they sync between your devices.

Install Denset

Firefox 140 or later, desktop only.

Installing

  1. Open this page in Firefox and click Install Denset.
  2. If Firefox says it prevented this site from installing software, click Continue to Installation.
  3. Click Add. Denset updates itself from now on.
  4. Optional: click the puzzle-piece button in the toolbar and pin Denset so its button is always visible.

Getting started

  1. Click the Denset button, type a name such as Work and press Enter.
  2. Right-click any tab and choose Add to set > Work. Or, when creating a set, choose From > a tab group or the whole window.
  3. Click Open on the set to open its tabs as a tab group. Reset puts them back to their default pages.
  4. Click the arrow beside a set for its tabs and options, such as an overview page as the landing tab.

Sets live in Other Bookmarks > Denset, so Firefox Sync carries them to your other devices. Denset collects no data.
